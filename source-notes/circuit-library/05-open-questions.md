# 05 — Open questions

1. **Capability versus expression:** When does a modification create a capability rather than remove an obstruction?
2. **Portability:** What survives translation between different architectures?
3. **Interference:** How can composed entries be checked for unintended interaction at scale?
4. **Verification:** What tests distinguish intended improvement from collateral degradation?
5. **Provenance:** How should entry derivation, forks, and corrections be represented?
6. **Authority:** Who authorizes modifications to a target, and how is approval recorded?
7. **Self-application:** Under what circumstances, if any, could a reader apply a library entry to itself, and what external controls would be required?
8. **Evidence:** Which conclusions from preliminary weight-editing results survive independent reproduction?
